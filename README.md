# Console Bank Application (Java)

A menu-driven banking application built in Java that runs in the terminal.

## Features
- Admin login with email and password
- Open a customer account (name, account number, PIN, initial balance)
- View customer account details
- Close a customer account
- Input validation, for example when an account number does not exist

## Tech Used
- Java
- Object-Oriented Programming (OOP)
- Exception handling
- IntelliJ IDEA

## How to Run
1. Download or clone this repository
2. Open the project in IntelliJ IDEA (or any Java IDE)
3. Run `bankApp.java`
4. Choose an option from the menu:
   1. Admin Login
   2. Customer Login
   3. Exit
